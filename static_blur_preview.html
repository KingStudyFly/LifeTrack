三层结构 → 安卓资源映射

Layer 1
预渲染模糊背景（静止）
对应 bg_frosted：启动时把色斑模糊成一张位图，之后永不再算。
Layer 2
极淡色块层
对应 bg_glass_blobs：纯半透明色块，不需要 filter:blur。
Layer 3
玻璃元素
对应 bg_card / glass_input / bg_page_label：半透明色 + 0.5dp 细边框 + 阴影。

为什么这个版本能流畅落地

旧预览的色块用了 filter: blur(100px) + 浮动动画 —— 这部分安卓复现不了。 本页把"模糊感"全部收进 Layer 1 的一张静态图（radial-gradient 天然近似高斯模糊的观感）， 其余层只是叠半透明色，GPU 只做合成，不重算。

对比实验

点右上角 「对比：实时模糊」，手机框会切到 backdrop-filter 实时模糊。 你会发现视觉效果几乎没差别 —— 但在安卓上，右边那版每一帧都要截图 + 重算模糊，正是当年卡顿的根源。

配色（取自 colors.xml）

green_primary #8B9A7D
brown_light #C4A77D
brown_accent #B8A99A
bg_primary #FAF8F5（深色 #121212）
结论：你要的效果 = 「一张模糊的背景图 + 半透明玻璃层」。这在安卓上是零成本的， 和 HTML 预览的差距只差"把背景模糊做成一张预渲染位图"。
