# flomo 浮墨笔记调研

## 2026-07-02 — 调研要点

### 基本信息
- 产品名：flomo（浮墨笔记），flomo = flow + memo
- 开发者：少楠 + lightory（白光），2人全职团队
- 公司：上海仙蒂网络科技有限公司
- 上线时间：2020年12月
- 平台：iOS / Android / Web / PWA / 微信服务号
- 官网：flomoapp.com

### 产品哲学
- 核心理念：降低输入摩擦，提高输入动机
- 受尼克拉斯·卢曼卡片盒笔记法 + Andy Matuschak EvergreenNote 影响
- "只给自己看的微博" / "加强版文件传输助手"
- 关注"记录"而非"写作"；关注"个体"而非"企业协同"
- 拒绝做 All-in-one，拒绝做完美产品

### 商业模式
- 免费 + PRO 订阅
- PRO：99元/年 或 12元/月，教育优惠 49-59元/年（无需验证）
- 不卖永久会员，承诺"再服务7年"服务保证金
- 不融资，不靠广告
- 免费版 500M 空间限制

### 核心功能
- 聊天式输入（像发微博）
- 多级标签 #标签/子标签
- 每日回顾（微信推送、Widget）
- 随机漫步（语义分析）
- 相关笔记（4.0，双链 @）
- 全文搜索
- API（iOS 快捷指令、Alfred、Chrome、Telegram Bot）
- Widget（主屏、锁屏、iOS 18 控制中心）
- 自建云同步（非 iCloud），永久免费
- 导出 HTML / Markdown（7天一次）
- 深色模式
- 微信语音输入

### 设计哲学（官方）
- 尽量少设计、少颜色、少个性、少 ego
- 复用性，形成韵律
- 有原研哉的影子

### 技术选型
- 首版用 Web + PWA，后转原生 iOS/Android
- 不用 iCloud（要服务全平台用户）
- 团队 2 人，成本控制极端严苛
- 早期单核服务器，未部署 ElasticSearch

### 用户评价
- 好评：极简无压、微信输入顺滑、改变记录习惯、帮助思考
- 差评：功能少、标签要手动加#符号、不支持富文本、免费空间小、价格争议

### 收购
- 2022年收购飞书旗下「幕布」，幕布继续独立运营

## 2026-07-02 — 对标 LifeTrack 改进决策

### 核心判断
LifeTrack 和浮墨走的不是一条路。LifeTrack 偏向结构化深度分析和 AI 洞察问答，浮墨偏向无压力快速记和被动回顾。两者互补而非替代。

### LifeTrack 必须保留的差异化
- AI 周期总结（6 种周期，带结构化洞察）
- 结构化标签 AI 提取（人物/项目/事件/情绪/决策）
- AI 聊天式洞察问答
- 图片/语音识别记录
- SQLCipher 加密

### 对标改进清单（12 条）
**P0（2 周内）**：
- P0-1 增加 Markdown 导出格式
- P0-2 偏好设置页实装（不再 toast）
- P0-3 Record 页保存流程简化（消除二次选择）
- P0-4 多级标签系统（手动 + AI 双轨，需 v10 迁移）

**P1（1-2 个月）**：
- P1-1 桌面 Widget（快速记录 + 每日回顾）
- P1-2 每日回顾推送（本地通知）
- P1-3 相关日记双链 @
- P1-4 随机漫步功能
- P1-5 系统分享到 LifeTrack

**P2（3-6 个月）**：
- P2-1 Web 端 + PWA
- P2-2 极简输入模式开关
- P2-3 设计风格向克制调整（双主题）

### 关键决策点（待用户确认）
1. P0-4 多级标签是否要上，涉及数据库 v10 迁移
2. P1-1 Widget 形态：仅输入跳转 / 仅回顾展示 / 两者都要
3. P1-2 推送默认时间：21:00 / 22:00 / 用户自选

## 2026-07-02 — AI洞察技术机制调研

### AI洞察产品机制
- 功能定位：flomo不做AI扩写/润色，只帮用户「看见真实的自己」
- 触发方式：搜索笔记后洞察、多视角洞察（MBTI/CBT/逆向思考/主题归纳）、随机回顾增强
- 产品克制：AI是镜子，不是笔；不替代用户思考

### 核心技术架构（RAG）
- 检索：向量Embedding + 语义检索，召回Top-K相关笔记
- 生成：调用DeepSeek API，动态切换System Prompt（按视角）
- 关键约束：检索范围限定个人笔记库，AI必须标注引用来源
- 冷数据激活：语义检索打破时间线壁垒，让旧笔记重新变「热」

### 提示词工程特点
- System Prompt按洞察视角动态组装（MBTI分析师/CBT治疗师等角色）
- 从召回的几十条笔记中筛选十几条最具代表性的作为上下文
- 强制要求模型引用具体笔记编号，提高可信度

### 笔记数据结构优势
- 卡片式原子笔记：粒度小、主题聚焦，便于Embedding
- 用自己的话记录：个人特征强，为AI提供高质量上下文
- 层级标签：如 `#阅读/心理学/认知偏差`，提供结构化过滤维度

### 对LifeTrack Insight模块的启示
- 多视角洞察框架：Insight模块可引入情绪分析/行为模式/健康关联等视角
- 引用可追溯：AI分析结果必须标注来源日记
- 冷数据激活：日记类应用「写后就忘」，需AI主动挖掘历史价值
- 差异化方向：时间序列分析、多媒体融合、目标关联、隐私优先（本地模型）
